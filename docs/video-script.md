# Demo video: shot list and narration

About two minutes. Record the live demo at https://namesake.bogdansabau.eu in a 1440-wide browser window. Same claim rules as the README: say "drafts", "screens", "an experiment"; never "adopted faster", "saves lives" or "matches".

| Time | On screen | Narration |
|---|---|---|
| 0:00–0:12 | Start page, scroll over the animal grid | "Shelter volunteers write a listing for every animal, often in a hurry. Namesake's AI drafts an accurate listing, screened name options and a plan to get the animal seen, using Qloo taste data near the shelter." |
| 0:12–0:20 | Hover the large brindle dog (`dog-02`, long stay badge); pick Park Slope | "Large adult dogs wait longest. This one has been here eight months. The shelter is in Park Slope, Brooklyn." |
| 0:20–0:45 | Under **Read a finished story**, click "The brindle dog in Park Slope". Scroll slowly down the result | "The listing restates only what the shelter recorded: third person, behaviour toward people first. Anything not recorded, like how she is with children, is left out and listed as unknown. Code checks each sentence against the facts before the volunteer sees it." |
| 0:45–1:00 | Click **Generic**, then **Local, with Qloo** (each button also shows its version's name) | "Here's the test the hackathon asks for: would this work the same without Qloo? Generic and local share the same bio. The local version adds a name from a title Qloo found strong in the area, and one line saying where it comes from. That difference is what Qloo adds." |
| 1:00–1:15 | Name options: point at the line labelled Qloo and the one labelled Namesake's AI | "Each name shows what Qloo returned, kept apart from the reasoning of Namesake's AI. Every option is screened for villains, aggression words and identity-coded references, with the strictest screen for bully-breed dogs." |
| 1:15–1:35 | Map and **Places to ask**: point at "3rd of 15 · near the top" and "not among the 15 places for fans of this area's top shows", then the key on the map | "Namesake's AI asked Qloo which places near the shelter fans of these pet-themed titles favour, and compared them with fans of what this neighbourhood watches most. Places that only show up for the pet-themed titles stand out, and Namesake's AI picks those first among the places near the top of Qloo's list. Each one carries its rank. The map shows where in the neighbourhood those fans stand out." |
| 1:35–1:45 | Under **How Namesake made this**, open **Everything Qloo returned, and how Namesake read it**, and the folded **How this run went, step by step** | "The Why panel separates Qloo's answers from how Namesake read them, its AI and its code, for every choice." |
| 1:45–1:55 | Back to start; pick **Austin** and another animal; show the Working page's live log for a few seconds | "For a new animal, Namesake's AI works live: it starts from the pet titles Qloo lists for the area, settles ambiguous names, picks venues, and plain code checks everything it returns." |
| 1:55–2:05 | Return to the dog's result, scroll to **Other ways to help: get her seen** | "The plan leads with what research supports: foster networks, outings, timing. The local layer is an experiment, and Namesake records what a trial would need to test it." |
| 2:05–2:10 | Title card: Namesake · namesake.bogdansabau.eu · github.com/bsabau/namesake | "Taste data from the Qloo API. Namesake isn't affiliated with Qloo." |

Tips:
- Open the example links before recording, so each loads instantly from the cache.
- A live run spends Qloo quota and takes about a minute for a new area. Austin's dog profile is already cached, so a dog there takes a few seconds; trim the wait in editing if needed.
- Keep the cursor still while narrating a section; zoom the browser to 110% if the text is small.
